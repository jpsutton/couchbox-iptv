# M0: player comparison (2026-10-04)

Lenovo M715q (AMD Ryzen with Radeon Vega 11, Mesa 26.2.4, kernel 7.2.8),
Plasma Bigscreen on Wayland, 1080p60 TV. `couchbox-iptv --bench`: each of 10
iptv-org streams tuned on both backends in turn, then watched for 20 s. Raw
numbers: `m0-results.json`.

| Stream | Tune native / media_kit (ms) | CPU native / media_kit |
|---|---|---|
| Fox Weather 1080p | 2489 / 2039 | 11% / 31% |
| Bloomberg Originals 1080p | 2525 / 2845 | 12% / 30% |
| Telemundo San Diego 1080p | 5012 / 2642 | 11% / 31% |
| CBS News 24/7 720p | 2549 / 1636 | 12% / 30% |
| MST3K 1080p | 3909 / 3766 | 11% / 30% |
| Deal or No Deal 1080p25 | 4300 / 3819 | 11% / 28% |
| Newsmax 720p | 3103 / 2933 | 12% / 30% |
| Shop LC (DASH) | failed / failed | - |
| TBN Armenia (MPEG-TS) 1080p | 5310 / 5164 | 9% / 28% |
| Teletica 7 (Referer header) 720p | 3036 / 2886 | 13% / 30% |

CPU is the app process (mpv runs in it), as a share of one core.

- **Hardware decoding:** VA-API on every stream, both backends.
- **Dropped frames:** native 0-1 per stream (at the start), media_kit 0.
  Decoder drops 0 everywhere. Watched on the TV: smooth on both.
- **CPU:** native about 11%, media_kit about 30%: the texture copy into
  Flutter costs nearly three times as much.
- **Tune time:** similar, 1.6-5.3 s, set by the stream. The two use different
  "first frame" signals (native: mpv's playback-restart; media_kit: a video
  size while not buffering), so small differences mean little.
- **Preview box** (640x360, top right): correct on both.
- **Headers:** Teletica 7 needs a Referer; it played on both.
- **Shop LC (DASH):** FFmpeg's DASH demuxer cannot read this live manifest
  ("Unable to read to manifest", then a TLS read error), with plain mpv too.
  A stream problem, not a backend one. DASH is 228 of 18,139 iptv-org streams;
  the nightly check will mark failures like this dead.
- **Telemundo, music but no dialogue:** the stream has one audio track per
  quality level, so mpv had nothing else to pick; most likely what was airing.
- **TBN Armenia** is in Armenian: needs preferred audio and subtitle languages
  (mpv `alang`/`slang`) and the language filter.

**Decision: the native plane is the default backend.** media_kit stays behind
the `LivePlayer` interface only as long as it is useful for comparison.
